# Contributor guidance

Read README.md and AI_DEVELOPMENT.md before changing source. Preserve separate direct-service, hero-reader, and Game view capabilities. Keep native write/hook hash and live-code checks strict; do not guess offsets. Read-only hero detection uses validated resource ownership and stable data instead of a version gate. Run build.ps1 and test.ps1. Do not silently add network calls to tests. Keep credentials, personal data, game files and captures out of commits. Keep AI-assistance disclosure accurate. Never claim player-visible results from offline checks.
