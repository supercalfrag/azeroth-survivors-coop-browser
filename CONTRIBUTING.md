# Contributing

Build with `build.ps1` and run `test.ps1` on Windows. Keep dependencies optional and preserve manual refresh and copy-code behavior. Describe the concrete change and state which checks were offline, live read-only, or player-visible.

AI-assisted contributions are welcome. Review generated code, disclose substantial AI assistance, and do not claim live validation from mocks. Keep native compatibility checks strict. Do not submit personal saves, player-list captures, credentials, game binaries, or extracted artwork.
